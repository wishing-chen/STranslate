# STranslate · Rounded UI

基于上游 **v2.0.10 / 2a75118fe0fabc1135a619f4393eb3a8d936c5cd** 的 Windows WPF 界面分支。保留 STranslate 的翻译、OCR、图片翻译、语音、生词本、历史记录和插件能力。分支：`ui/apple-rounded`。

## 使用

打开交付目录 `STranslate-Apple/STranslate.exe`。需要 Windows 和 .NET 10 Desktop Runtime；本机已安装。`PortableConfig` 随程序保存此副本的配置，不需要把原版配置移过来。程序仍沿用上游单实例机制，因此运行前应先退出已有 STranslate。

主窗口从上到下是：常用操作、语言选择、输入卡、翻译结果。截图、OCR 和服务开关在顶部；其它操作在“更多操作”内，设置在右端。语言两侧可直接选择，中间交换；临时服务图标单独换行。翻译按钮在输入区右下角，原来的 Enter、Esc 和其它快捷键继续有效。

服务浮层是各服务的**独立启停**，可以同时启用多个服务。圆形图标固定大小、错峰上浮淡入，展开 420 ms、收起 230 ms，中途可反向。选择后收起，恢复输入焦点；外部点击保持原点击意图。跟随 Windows“动画效果”设置，关闭系统动画后直接切换。

自动检查上游更新默认关闭：官方更新会覆盖这个 UI 分支。手动更新入口仍沿用上游，更新前应自行确认。没有加入 Apple 字体或 SF Symbols，继续使用系统字体和原有 Fluent 图标。

## 从源码构建

安装官方 .NET 10 SDK 后，在仓库根目录执行：

```powershell
./build-ui.ps1
# 或指定便携 SDK：
./build-ui.ps1 -Dotnet 'D:/path/to/dotnet.exe'
```

产物位于 `src/.artifacts/Release/`，包含所有内置插件。构建脚本保留输出中的现有配置，不做递归删除，不创建安装包、不注册启动项。首次运行程序时会执行上游正常的应用初始化。
